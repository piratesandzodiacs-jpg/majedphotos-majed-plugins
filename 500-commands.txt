# 500 Image Commands — majedphotos
# Format: /command | description to apply to the generated image
# Usage: start a message with one or more commands, then the topic.
#   Example: /portrait /goldenhour /kodak a falcon handler in the desert
# Commands combine freely. Later commands refine earlier ones; on conflict, the last one wins.
# Any Arabic text in an image must be correct, right to left, with properly joined letters.
