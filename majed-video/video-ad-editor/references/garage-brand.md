## ⛔ القاعدة الذهبية — رقم اللوحة ما يبين أبداً

سيارات الزباين: **رقم اللوحة ما ينقرا ولا بفريم وحد** — بالريل، بالكفر، بالثمبنيل، بالمونتاج، وبورقات المراجعة اللي تنرسل.
الكراج يغطيها بتصميم لوحته الخاصة.

1. **افحص كل مقطع سيارة** بورقة الفريمات (الخطوة اللي تشوف فيها المواد بأي سكل). أي لوحة مقروءة = لازم تتغطى.
2. **أسهل حل أول:** اختار لحظة ثانية ما تبين فيها اللوحة، أو قص/زوم يطلّعها برّا الكادر.
3. **ما ينفع؟ غطّها** قبل ما يدخل المقطع المونتاج:
   ```bash
   python3 scripts/45_plate_cover.py grid <مقطع> <ثانية>          # تقرا مكان اللوحة x,y,w,h
   python3 scripts/45_plate_cover.py cover <مقطع> <مقطع_مغطى.mp4> \
       --key "0,x,y,w,h" --key "3.5,x,y,w,h" --track --cover <work>/plate-cover.png
   python3 scripts/45_plate_cover.py check <مقطع_مغطى.mp4>        # افتح الورقة بعينك
   ```
   - لقطة ثابتة = مفتاح واحد. الكاميرا تتحرك = مفتاح كل ما يتغيّر مكان اللوحة وايد (كل 1–2 ث)، و`--track` يتبعها بينهم.
   - **تصميم لوحة الكراج:** `~/.video-ad-editor/plate-cover.png`. موجود؟ انسخه لـ`<work>/plate-cover.png`. مو موجود؟ اطلبه منه **مرة وحدة** («عطني صورة لوحة الكراج اللي تغطون فيها الأرقام») واحفظه هناك. لين يوصل: بلا `--cover` (تغبيش قوي)، وقل له بسطر.
   - بعدها كمّل الشغل على المقطع المغطّى بداله الأصلي: انقل الأصلي لـ`<work>/_originals/` وحط المغطّى بنفس الاسم بمجلد المواد، حتى أي سكربت بعدها (`inspect`، `12_montage.py`…) ياخذ المغطّى.
4. **قبل التسليم:** بفحص الريل النهائي (ورقة الفريمات/`qa.jpg`) دوّر اللوحات مرة ثانية. لوحة مقروءة = ⛔ لا تسلّم.
5. الكفر والثمبنيل: نفس القاعدة — لو الصورة فيها لوحة، غطّها قبل التصميم.

لوحات سيارات ثانية بالخلفية (سيارات بالكراج أو بالشارع) نفس الحكم.

## كرت الختام (`theme.outro`) — بدل إعلان السكل

⛔ الافتراضي بالمحرّك إعلان البلقن نفسه — **لازم** يتغيّر بكل فيديو. الافتراضي للكراج:

```json
"handle": "@repair_painting_cars",
"outro": { "l1": "كراج موسى محسن TRD", "l2": "المعبيلة الصناعية · مسقط",
           "chips": ["ترجيع شواصي", "صبغ وتصليح", "تلميع وتغليف", "تعديل وتيونق"],
           "cta": "كلّمنا واتساب", "word": "‎98880043‎", "sub": "اتصال أو واتساب — نرد عليك" }
```
شكل الكرت (من `outro()` بالمحرّك): الشعار ← `l1`/`l2` رمادي ← 4 كبسولات `chips` ← `cta` كبير ← `word` بالقرص الملوّن ← `sub` ← الشعار الصغير + `handle`.
- ⛔ **لازم `chips` تنكتب** (حتى لو `[]`) — بدونها يطلع إعلان البلقن نفسه («شيل السكتات»، «كابشن لحظي»…). 
- الكبسولات تتغيّر على موضوع الفيديو (فيديو تغليف ← «تغليف كامل»، «حماية PPF»… لو هو قالها) — 4 بالكثير، كل وحدة 14 حرف أو أقل.
- الهدف من كل فيديو: **يتواصل واتساب أو يتصل**، مو «علّق بكلمة». لو طلب «علّق بكلمة X» ← `cta:"علّق بكلمة"`, `word:"X"`.
- الرقم بالقرص محاط بـ`U+200E` حتى ما ينقلب. بالـJSON اكتبه `‎`.
- `00_onboard.py theme` يكتب كرت ثاني من الملف المحفوظ — بعده **ارجع اكتب `outro` هذا** فوقه (إلا لو هو غيّره).
