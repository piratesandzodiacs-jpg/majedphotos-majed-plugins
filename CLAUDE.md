# Image commands (/commands)

- The command dictionary lives in `500-commands.txt` at the repository root.
- When a message starts with one or more `/commands`, look each one up in `500-commands.txt` and apply its description to the generated image, together with the topic written after the commands.
- Several commands can be combined (e.g. `/portrait /goldenhour /kodak`): apply all of them together.
- If a command is not in the file, say so and suggest the closest command from the file.
- Any Arabic text inside an image must be written correctly, right to left, with properly joined letters.
